Projeto Integrador

Este site foi desenvolvido para promover a acessibilidade digital de pessoas com baixa visão ou cegueira através de tecnologias assistivas.

📚 Flashcards

Baixa Visão

É uma deficiência visual que dificulta a leitura mesmo utilizando óculos.

Leitor de Tela

Software que transforma textos em voz para pessoas cegas.

HTML Semântico

As tags semânticas ajudam leitores de tela a interpretar corretamente o conteúdo.

🤖 Robótica

Bengala Inteligente

Utiliza sensores para detectar obstáculos e emitir alertas sonoros ou vibração.

Arduino

Permite criar projetos acessíveis de baixo custo para pessoas com deficiência visual.

Robôs Assistivos

Podem auxiliar na locomoção e identificação de ambientes.

Inteligência Artificial

Reconhecimento de voz, objetos e textos para aumentar a autonomia das pessoas.

Óculos Inteligentes

Equipamentos capazes de identificar pessoas, objetos e placas.

Assistentes Virtuais

Permitem realizar tarefas utilizando apenas comandos de voz.
